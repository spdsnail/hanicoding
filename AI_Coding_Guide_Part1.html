AI 코딩 시작하기

코드를 한 줄도 직접 작성하지 않고, AI에게 말로 첫 프로그램을 만드는 실습 가이드

01. 코딩을 몰라도 프로그램을 만들 수 있다

사용자는 원하는 결과를 설명하고, AI는 프로그램 파일을 만듭니다. 코딩 문법을 먼저 배울 필요는 없습니다.

예를 들어 “메모를 추가하고 지울 수 있는 웹페이지를 만들어 줘”라고 말합니다. AI가 파일을 만들면 사용자는 화면을 열어 확인하고, “검색 기능도 추가해 줘”라고 이어서 요청합니다.

코드를 몰라도 시작할 수 있지만, AI가 만든 결과가 맞는지 확인하고 오류를 발견하면 알려 주는 일은 사용자의 역할입니다.

02. AI 채팅과 AI 코딩 도구의 차이

일반 AI 채팅AI 코딩 도구
설명이나 코드를 답변으로 받는 일이 중심허용된 프로젝트 폴더의 파일을 직접 읽고 수정
코드 복사·붙여넣기, 파일 재업로드가 필요할 수 있음동일한 파일을 계속 수정해 버전 혼동 감소
실행과 수정 연결을 사용자가 관리할 수 있음실행·테스트도 도구가 도와줄 수 있음

중요한 것은 내 컴퓨터의 프로젝트 폴더를 AI에게 연결하는 것입니다. AI에게 컴퓨터 전체를 열어 줄 필요는 없습니다.

04. 설치하고 시작하기

Windows 기준: 그래픽 앱으로 시작

1
Codex 선택: ChatGPT 공식 다운로드에서 데스크톱 앱을 설치하고 로그인합니다. 앱에서 Codex로 이동합니다. Windows 공식 사용법을 참고하세요.
2
Claude Code 선택: Claude 공식 다운로드에서 데스크톱 앱을 설치하고 로그인합니다. Code 탭을 엽니다.
3
문서 폴더 안에 AI프로젝트 폴더를 만들고, 그 안에 내첫메모장 폴더를 만듭니다.
4
AI 코딩 앱에서 내첫메모장 폴더를 작업 대상으로 선택합니다. 접근 권한 요청을 읽고 승인합니다.
바탕화면 전체, 문서 폴더 전체, 비밀번호나 개인정보가 든 폴더를 프로젝트로 선택하지 마세요. 설치나 실행 과정에서 명령어가 필요하다면 공식 안내를 확인하고, 의미를 모르는 관리자 권한 요청은 바로 승인하지 마세요.
첫 대화
저는 코딩을 전혀 모릅니다. 현재 열려 있는 프로젝트 폴더가 무엇인지 확인해 주세요. 앞으로 파일 생성과 수정은 이 폴더 안에서 진행하고, 실행 방법은 쉬운 한국어로 설명해 주세요.

05. 첫 프로그램 만들기

첫 실습은 인터넷 연결 없이도 열 수 있는 간단한 메모장 웹페이지입니다. 외부 서버나 데이터베이스는 사용하지 않습니다.

AI에게 이렇게 말하세요
이 프로젝트 폴더에 간단한 메모장 웹페이지를 만들어 주세요.

필요한 기능:
1. 메모를 입력하고 추가하기
2. 기존 메모 수정하기
3. 메모 삭제하기(삭제 전 확인)
4. 브라우저를 새로 열어도 메모가 남도록 이 컴퓨터에 저장하기

가능하면 HTML, CSS, JavaScript만으로 간단하게 만들어 주세요. 코드를 저에게 붙여넣으라고 하지 말고 프로젝트 파일을 직접 생성해 주세요. 완성되면 여는 방법을 알려 주세요.

예상 결과

메모 입력 칸, 추가 버튼, 메모 목록이 나타납니다. 저장에는 브라우저의 로컬 저장소를 사용할 수 있습니다. 저장된 메모는 해당 브라우저·기기에만 남으며, 다른 기기와 자동 동기화되지는 않습니다.

성공 기준: 메모를 추가하고, 수정하고, 삭제한 뒤 페이지를 새로 열어도 남아 있는 메모가 유지됩니다.

06. 프로그램 실행하고 확인하기

웹페이지 파일을 만들었다고 자동으로 화면이 열리는 것은 아닙니다. AI에게 실행 방법을 물어보세요.

AI에게 이렇게 말하세요
완성된 메모장을 지금 확인하고 싶습니다. 가장 쉬운 실행 방법을 알려 주고, 가능하면 직접 실행하거나 미리보기를 열어 주세요. 제가 클릭해야 할 것이 있다면 순서대로 알려 주세요.

단일 HTML 파일이라면 파일을 더블클릭해 브라우저에서 열 수 있습니다. 개발 서버가 필요한 구성이라면 AI가 필요한 도구와 실행 절차를 안내하도록 합니다.

직접 확인

AI가 “테스트 완료”라고 답해도 실제 화면은 직접 확인하세요. AI가 브라우저 화면을 볼 수 없는 환경도 있습니다.

07. 말로 기능 추가하고 디자인 바꾸기

처음부터 모든 기능을 요청하기보다 한 번에 한 가지 변화를 요청하면 결과를 확인하기 쉽습니다.

기능 추가
기존 메모 기능은 유지하면서 메모 검색 기능을 추가해 주세요. 검색어를 입력하면 해당 글자가 포함된 메모만 보이게 해 주세요. 수정 후 기존 추가·수정·삭제 기능도 정상인지 확인해 주세요.
디자인 수정
현재 메모장의 기능은 바꾸지 말고, 화면 디자인만 더 단정하게 바꿔 주세요. 버튼은 둥글게, 글자는 읽기 쉽게, 모바일 화면에서도 사용하기 편하게 해 주세요.

수정할 때는 “기존 기능 유지”, “바꿀 부분”, “확인할 결과”를 함께 말하는 것이 유용합니다.

08. 오류를 AI에게 해결시키기

버튼이 작동하지 않거나 화면이 깨지면 오류 문구나 화면 캡처를 전달합니다. 코드를 직접 찾아 고칠 필요는 없습니다.

AI에게 이렇게 말하세요
메모장에서 [어떤 버튼/기능]이 작동하지 않습니다. [실제 증상 또는 오류 메시지]가 나옵니다. 프로젝트 파일을 확인해 원인을 찾고 수정해 주세요. 수정 후 기존 기능도 점검하고, 무엇을 고쳤는지 쉬운 한국어로 알려 주세요.
오류가 계속되면 “방금 변경한 부분과 이전에 정상 작동했던 상태를 비교해 주세요”라고 요청하세요. 화면에 나타난 오류 문구는 가능한 한 그대로 전달하는 것이 좋습니다.

09. 안전하게 작업하기

AI가 프로젝트 밖의 파일에 접근하거나 중요한 파일을 삭제하려 하면 이유를 먼저 확인하세요. AI가 “완료”라고 답해도 실제로 작동하는지 직접 확인합니다.

비밀번호·API 키·개인정보는 어떻게 관리할까요?

실제 비밀번호나 API 키를 AI 대화창에 붙여넣거나 코드에 직접 적지 마세요. 하지만 외부 서비스를 사용하는 프로그램은 실행할 때 키가 필요할 수 있습니다. 키를 무조건 프로젝트 밖으로 옮기는 것이 정답은 아닙니다. 프로그램은 지정된 경로나 환경 변수에서만 키를 읽으므로, 상위 폴더에 옮기면 자동으로 찾아 읽지 못할 수 있습니다.

보통은 실행 환경에 비밀값을 별도로 설정하거나, 필요한 경우 프로젝트 안의 .env 같은 설정 파일을 사용하되 .gitignore로 Git 저장 대상에서 제외합니다. Git 제외와 외부 공유 금지는 별개의 조치이므로 파일 공유·배포 시에도 따로 확인해야 합니다. 상위 폴더에 놓아도 AI에게 접근 권한이 있다면 읽을 수 있으므로 위치만으로 비밀이 보호되지는 않습니다.

AI에게 이렇게 말하세요
이 프로그램에 비밀번호나 API 키가 필요한지 확인해 주세요. 실제 비밀값은 대화창이나 소스 코드에 넣지 않겠습니다. 프로그램이 정상 작동하도록 환경 변수 또는 별도 설정 파일을 안전하게 연결하고, 비밀값이 포함된 파일은 Git 저장·공유·배포에서 제외해 주세요. 비밀값을 직접 보여주거나 출력하지 말고, 제가 설정해야 할 부분만 쉽게 안내해 주세요. 중요한 삭제나 프로젝트 밖 접근은 먼저 승인받아 주세요.

중요한 변경 전에 폴더를 복사해 두는 방법도 있지만, 2편에서는 Git을 AI가 관리하도록 설정해 반복적인 복사 작업을 줄입니다. Git은 이전 상태를 기록하는 ‘프로그램의 타임머신’입니다. 다만 Git은 외부 백업을 자동으로 대신하지 않습니다.

10. 저장하고 다시 시작하기

작업 결과는 대화창 안이 아니라 프로젝트 폴더에 저장됩니다. 다음 날 같은 폴더를 다시 열면 작업을 이어갈 수 있습니다.

1
AI 코딩 앱을 종료하기 전에 메모장이 정상 작동하는지 확인합니다.
2
다음에 앱을 열어 내첫메모장 프로젝트 폴더를 다시 선택합니다.
3
AI에게 현재 프로젝트를 살펴보고 이어서 작업해 달라고 요청합니다.
AI에게 이렇게 말하세요
기존 기능을 유지하면서 다음 작업을 이어가겠습니다. 어떤 기능을 추가하면 좋을까요?
