STEP 0 · 왕초보 필수 준비

명령어 창(PowerShell · 터미널) 여는 법 & 연습 폴더 만들기

검은 창이 처음이라도 걱정 마세요! 딱 두 가지만 알면 오늘 설치의 80%는 끝난 겁니다.

💡 터미널 / PowerShell이 뭔가요?

마우스로 아이콘을 더블클릭하는 대신, 컴퓨터에게 글자(명령어)로 일을 시키는 창입니다. 아래 적힌 명령어를 복사 버튼으로 복사해 붙여넣고 엔터만 누르면 됩니다.

💡 왜 '연습용 폴더'를 만드나요?

AI 코딩 도구는 "지금 열려 있는 폴더" 안의 파일들을 읽고 작업합니다. 바탕화면 전체나 내 문서 전체 대신, 안전한 빈 폴더에서 시작하는 것이 정석입니다.

💡 멈추거나 끄고 싶을 땐?

AI가 대답 중일 때 멈추려면 Ctrl + C를 누르세요. 대화를 완전히 종료하고 나오려면 채팅창에 /exit를 치고 엔터를 누르면 됩니다.

🪟 Windows에서 명령어 창 열기 Windows 10 / 11 공통
  1. 1
    키보드 왼쪽 아래 ⊞ 윈도우 키를 누르고 PowerShell을 입력합니다.

    ⚠️ 주의: 이름 옆에 (x86)이 적힌 것은 옛날 32비트용이니 누르지 마시고, 기본 Windows PowerShell (또는 터미널)을 클릭해 여세요. 관리자 권한으로 열 필요도 없습니다.

  2. 2
    창 맨 앞에 PS C:\Users\이름>처럼 맨 앞에 PS라는 글자가 보이면 성공입니다!

    붙여넣기는 창 안에서 마우스 오른쪽 클릭 또는 Ctrl + V를 누른 뒤 Enter를 치면 됩니다.

  3. 3
    나중에 AI를 실행할 연습용 폴더(ai-workspace)를 미리 하나 만들어 둡시다.
    PS>mkdir "$HOME\Desktop\ai-workspace"

    위 한 줄을 실행하면 바탕화면에 ai-workspace라는 새 폴더가 생깁니다.

🍎 Mac에서 터미널 창 열기 Apple Silicon(M1~M4) / Intel 공통
  1. 1
    키보드에서 ⌘ Command + 스페이스바를 동시에 눌러 Spotlight 검색창을 띄웁니다.
  2. 2
    터미널 (또는 영어로 Terminal)을 입력하고 Return(엔터)을 누릅니다.

    붙여넣기는 ⌘ Command + V를 누른 뒤 Return(엔터)을 치면 됩니다.

  3. 3
    나중에 AI를 실행할 연습용 폴더(ai-workspace)를 바탕화면에 미리 하나 만들어 둡시다.
    %mkdir -p ~/Desktop/ai-workspace

    위 한 줄을 실행하면 데스크탑(바탕화면)에 ai-workspace 폴더가 만들어집니다.

TOOL 1 · ANTHROPIC

1. 클로드 코드 (Claude Code) 설치하기

공식 한 줄 설치 명령어를 사용하면 복잡한 사전 프로그램 없이 설치되며, 이후 자동 업데이트까지 알아서 챙겨줍니다.

🪟 Windows 설치 순서 PowerShell 기준
  1. 1
    PowerShell 창에 아래 공식 설치 명령어를 복사해 붙여넣고 Enter를 누릅니다.
    PS>irm https://claude.ai/install.ps1 | iex

    글자들이 쭉 올라가며 설치 완료 메시지가 나올 때까지 10~30초만 기다리세요.

  2. 2
    [가장 중요!] 지금 열려 있는 PowerShell 창을 닫고, 새로 다시 여세요.

    창을 새로 열어야 윈도우가 방금 설치된 claude의 위치를 인식합니다.

  3. 3
    새로 연 창에서 잘 깔렸는지 버전을 확인합니다.
    PS>claude --version

    숫자(예: 2.x.xxx (Claude Code))가 뜨면 완벽하게 설치된 것입니다!

  4. 4
    연습 폴더로 이동해서 클로드 코드를 첫 실행하고 로그인합니다.
    PS>cd "$HOME\Desktop\ai-workspace"; claude

    테마 선택 후 엔터를 누르면 인터넷 브라우저가 자동으로 열립니다. Claude 계정(Pro 이상)으로 로그인하면 바로 대화를 시작할 수 있습니다.

🍎 Mac 설치 순서 터미널(Terminal) 기준
  1. 1
    터미널 창에 아래 공식 설치 명령어를 복사해 붙여넣고 Return을 누릅니다.
    %curl -fsSL https://claude.ai/install.sh | bash

    맥 비밀번호 입력 없이도 내 계정 폴더에 안전하게 바로 설치됩니다.

  2. 2
    [가장 중요!] 열려 있던 터미널 창을 완전히 닫고(⌘+Q 또는 새 탭 ⌘+T), 새 창을 여세요.
  3. 3
    새 터미널 창에서 버전을 확인합니다.
    %claude --version

    버전 숫자가 출력되면 정상 설치 완료입니다.

  4. 4
    연습 폴더로 들어가서 클로드 코드를 실행하고 로그인합니다.
    %cd ~/Desktop/ai-workspace && claude

    브라우저가 열리면 Claude 계정(Pro 이상)으로 로그인한 뒤, 터미널로 돌아와 한글로 안녕! 간단한 자기소개 웹페이지 하나 만들어줘라고 시켜보세요!

🩺 알아두면 든든한 상태 점검 명령어
설치 상태나 설정에 이상이 없는지 언제든 진단하고 싶다면 새 창에서 claude doctor를 입력해 보세요. 어디가 문제인지 친절하게 알려줍니다.
TOOL 2 · GOOGLE

2. Google Antigravity (agy) 설치하기

구글의 에이전트 도구로, 명령어 창에서 쓰는 CLI(agy)와 일반 프로그램처럼 마우스로 쓰는 데스크톱 앱 두 가지 중 원하는 방식을 고르거나 둘 다 설치할 수 있습니다.

🪟 Windows에서 agy CLI 설치 PowerShell 한 줄 설치
  1. 1
    PowerShell 창에 아래 공식 설치 명령어를 붙여넣고 Enter를 누릅니다.
    PS>irm https://antigravity.google/cli/install.ps1 | iex
  2. 2
    설치가 끝나면 PowerShell 창을 껐다가 새로 다시 엽니다.
  3. 3
    버전이 잘 나오는지 확인합니다.
    PS>agy --version
  4. 4
    연습 폴더로 이동해 agy를 실행하고 Google 계정으로 로그인합니다.
    PS>cd "$HOME\Desktop\ai-workspace"; agy

    초기 설정 안내에서 엔터를 누르면 브라우저가 열립니다. 평소 쓰는 Google 계정으로 로그인하면 바로 연동됩니다!

🍎 Mac에서 agy CLI 설치 터미널 한 줄 설치
  1. 1
    터미널 창에 아래 공식 설치 명령어를 붙여넣고 Return을 누릅니다.
    %curl -fsSL https://antigravity.google/cli/install.sh | bash
  2. 2
    설치가 끝나면 터미널 창을 새로 엽니다. (⌘+T)
  3. 3
    버전이 잘 나오는지 확인합니다.
    %agy --version
  4. 4
    연습 폴더로 이동해 agy를 실행하고 Google 계정으로 로그인합니다.
    %cd ~/Desktop/ai-workspace && agy

    브라우저에서 Google 계정 로그인을 승인하면 터미널에서 곧바로 대화가 시작됩니다.

🖥️ 검은 터미널 창 대신 마우스 화면으로 쓰고 싶다면? — Antigravity 데스크톱 앱 설치법

Antigravity는 카카오톡이나 크롬처럼 설치 파일만 받아 더블클릭으로 깔 수 있는 Antigravity App (에이전트 매니저)과 Antigravity IDE (코드 편집기)도 공식 제공합니다. agy CLI와 대화 내역·설정이 연동되니 초보자분들께 특히 추천합니다!

  • 공식 다운로드 주소: 브라우저 주소창에 https://antigravity.google/download 입력 후 접속
  • 🪟 Windows: 일반 PC는 Download for x64 (Antigravity-x64.exe) 클릭 → 다운로드된 파일 더블클릭 → 다음(Next)만 누르면 끝!
  • 🍎 Mac: M1·M2·M3·M4 맥은 Download for Apple Silicon (인텔 맥은 Intel) 클릭 → 받은 Antigravity.dmg 더블클릭 → 아이콘을 Applications(응용 프로그램) 폴더로 끌어다 놓으면 끝!
TOOL 3 · OPENAI

3. OpenAI Codex (codex) 설치하기

OpenAI의 공식 독립 설치 스크립트를 사용하면 Node.js나 WSL 같은 복잡한 사전 세팅 없이 윈도우와 맥 모두 한 줄로 설치됩니다.

🪟 Windows 설치 순서 PowerShell 네이티브 설치
  1. 1
    PowerShell 창에 아래 한 줄을 복사해 붙여넣고 Enter를 누릅니다. (보안 정책 우회 옵션이 이미 포함되어 있어 초보자도 에러 없이 바로 깔립니다!)
    PS>powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
  2. 2
    설치가 완료되면 열려 있던 PowerShell 창을 닫고 새 창을 엽니다.
  3. 3
    새 창에서 버전을 확인합니다.
    PS>codex --version
  4. 4
    연습 폴더로 이동해 codex를 실행하고 ChatGPT 계정으로 로그인합니다.
    PS>cd "$HOME\Desktop\ai-workspace"; codex

    화면에 Sign in with ChatGPT가 선택된 상태에서 Enter를 누르면 브라우저가 열립니다. ChatGPT 계정(Plus 이상)으로 로그인하면 완료입니다!

🍎 Mac 설치 순서 터미널 한 줄 설치
  1. 1
    터미널 창에 아래 공식 설치 명령어를 붙여넣고 Return을 누릅니다.
    %curl -fsSL https://chatgpt.com/codex/install.sh | sh

    참고: 만약 맥에 Homebrew가 이미 깔려 있는 분이라면 brew install --cask codex로도 설치할 수 있습니다.

  2. 2
    설치가 완료되면 터미널 창을 닫고 새로 다시 엽니다. (⌘+T)
  3. 3
    버전이 출력되는지 확인합니다.
    %codex --version
  4. 4
    연습 폴더로 이동해 codex를 실행하고 로그인합니다.
    %cd ~/Desktop/ai-workspace && codex

    Sign in with ChatGPT에서 Return을 눌러 브라우저에서 ChatGPT 계정(Plus 이상)으로 로그인하세요.

TROUBLESHOOTING · FAQ

설치하다 막혔나요? 초보자가 겪는 오류 99% 해결법

아래 질문을 클릭하면 해결 명령어와 방법이 바로 펼쳐집니다.

Q1. 분명히 설치 완료가 떴는데, 명령어를 치면 "찾을 수 없습니다 (command not found / 용어가 인식되지 않습니다)"라고 나와요!

원인 1순위 (90% 해결): 설치할 때 열어 두었던 창을 그대로 써서 그렇습니다. PowerShell이나 터미널 창을 완전히 닫고 새로 열어서 다시 입력해 보세요.

원인 2순위 (새 창에서도 안 될 때 — 경로 PATH 등록): 컴퓨터가 설치된 폴더 위치를 아직 못 찾는 경우입니다. 아래에서 내 컴퓨터에 맞는 한 줄만 복사해 실행한 뒤 창을 새로 여세요.

🍎 Mac 해결 한 줄 명령어 (터미널에 붙여넣기):
%echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
🪟 Windows 해결 한 줄 명령어 (PowerShell에 붙여넣기 후 새 창 열기):
PS>[Environment]::SetEnvironmentVariable("Path", $env:Path + ";$HOME\.local\bin;$env:LOCALAPPDATA\agy\bin", "User")
Q2. Windows PowerShell에서 빨간 글씨로 "이 시스템에서 스크립트를 실행할 수 없으므로..." 오류가 떠요!

윈도우의 기본 스크립트 보안 설정이 잠겨 있을 때 나타나는 흔한 안내입니다. PowerShell에 아래 명령어를 먼저 한 줄 실행한 뒤, 다시 설치 명령어를 실행하면 깔끔하게 통과됩니다.

PS>Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
Q3. 설치하고 로그인까지 성공했어요! 첫 질문은 뭐라고 말 걸면 좋나요?

영어나 코딩 용어를 전혀 몰라도 됩니다. 평소 메신저로 대화하듯 자연스러운 한국어로 시켜보세요!

지금 이 폴더 안에 깔끔한 디자인의 할 일 관리(To-Do) 웹페이지 index.html 파일을 하나 만들어줘.

다 만들어졌다고 하면 바탕화면의 ai-workspace 폴더를 열어 방금 만들어진 index.html 파일을 더블클릭해 보세요. 내가 만든 첫 프로그램이 눈앞에 열립니다!
