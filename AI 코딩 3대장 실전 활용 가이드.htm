PART 1 · CORE DIFFERENCE

웹사이트 일반 채팅 vs 내 컴퓨터 AI 코딩 에이전트, 뭐가 다른가요?

가장 쉬운 비유로 기억하세요. "전화 상담원"과 "내 옆자리에 앉아 직접 일해주는 비서"의 차이입니다.

기존 방식 · 웹 브라우저 채팅 (ChatGPT / Claude / Gemini 웹)

📞 유리창 너머의 '전화 상담원'

내 컴퓨터 안에 무엇이 있는지 전혀 볼 수 없습니다. 내가 직접 파일을 하나씩 업로드하거나 글을 복사해서 붙여넣어 줘야만 대답하며, AI가 짜준 결과물도 내가 다시 복사해서 파일로 저장해야 합니다.

내 손이 바쁨: 파일 업로드 → 질문 → 답변 복사 → 직접 붙여넣기 → 에러 나면 다시 복사해 질문
새로운 방식 · 로컬 AI 에이전트 (Claude Code / agy / Codex)

🧑‍💻 내 폴더 안에 상주하는 '실무 비서'

내가 열어준 폴더 안의 파일 수십 개를 스스로 열어 읽고 파악합니다. 지시만 내리면 내 컴퓨터에 실제 파일(웹페이지, 엑셀, 보고서 등)을 직접 만들고, 스스로 테스트해 오류가 있으면 알아서 고쳐 놓습니다.

AI가 다 처리: 한글로 한 줄 지시 → AI가 폴더 탐색 → 파일 직접 생성·수정 → 오류 자체 점검 완료!
비교 항목 웹사이트 일반 채팅 AI 코딩 에이전트 (claude · agy · codex)
내 파일 읽기 내가 직접 파일 첨부 버튼으로 올린 몇 개만 봄 (개수·용량 제한 있음) 작업 폴더 안의 수십~수백 개 파일과 하위 폴더 구조를 스스로 탐색해서 한꺼번에 읽음
결과물 완성 채팅창에 글자·코드로만 보여줌 (저장·실행은 내 몫) 내 폴더 안에 완성된 파일·폴더를 직접 생성 및 수정 (더블클릭하면 바로 열림)
에러가 났을 때 "에러 났어"라고 내가 화면을 캡처하거나 복사해서 다시 물어봐야 함 AI가 직접 실행해보고 에러 원인을 스스로 찾은 뒤 고쳐질 때까지 알아서 재시도함
컴퓨터 작업 실행 내 컴퓨터의 폴더 정리, 파일 이름 일괄 변경 같은 작업 불가능 내 허락(Yes) 하에 폴더 생성, 파일 분류, 데이터 합치기 등 실제 컴퓨터 작업 수행
내 취향 기억하기 새 채팅방을 열 때마다 배경 설명을 처음부터 다시 해야 함 폴더에 지침서(CLAUDE.md, AGENTS.md)를 하나 두면 언제 켜도 규칙을 자동 기억

작업할 폴더에서 켜기

3

확인 후 Yes 승인하기

AI가 파일을 만들거나 고치기 전에 허락을 구하면 내용을 슬쩍 확인하고 Enter(Yes)를 눌러 완성합니다. 마음에 안 들면 바로 말로 다시 고치게 하세요!

💡 한 끗 차이로 결과물이 천지 차이 나는 질문 비교

[무엇을 읽어서] + [어떤 파일 이름으로] + [꼭 들어갈 기능·디자인] 3가지만 넣어보세요.

❌ 아쉬운 질문 (너무 막연함)
"가계부 하나 만들어줘."

어떤 형태로 만들지(엑셀인지, 웹페이지인지, 파이썬 코드인지) 몰라서 초보자가 실행하기 어려운 복잡한 개발자용 코드를 뱉을 수 있습니다.

⭕ 최고로 잘 시키는 질문 (초보자 맞춤 황금 공식!)
"더블클릭하면 크롬에서 바로 열리는 가계부 웹페이지를 budget.html 파일 하나로 만들어줘. 날짜·내역·금액 입력칸과 카테고리별 합계 표가 들어가고 깔끔한 카드 디자인으로 해줘."

"더블클릭하면 바로 열리는 .html 파일 하나로"라고 지정해 주면 복잡한 설치 없이 누구나 바로 쓸 수 있는 완성품을 만들어 줍니다!

🖼️ 초보자 꿀팁: 말로 설명하기 답답할 땐 '스크린샷'을 끌어다 놓으세요!
세 도구 모두 이미지 인식을 지원합니다. 마음에 드는 디자인 캡처본이나 오류 화면 이미지를 터미널·앱 입력창에 마우스로 드래그 앤 드롭(끌어다 놓기) 한 뒤 "이 사진이랑 비슷한 레이아웃으로 만들어줘" 또는 "이 화면처럼 깨지는데 고쳐줘"라고 말하면 귀신같이 알아듣습니다.
PART 4 · CHEAT SHEET & 3 TOOLS

이것만 알면 중수! 필수 명령어 6개 & 3대장 골라 쓰는 법

대화창에 슬래시(/)를 치면 메뉴가 주르륵 나옵니다. 딱 아래 6개만 기억해 두세요.

입력 명령어 / 단축키 무슨 역할을 하나요? 언제 쓰면 좋나요?
/clear (또는 /new) 지금까지 나눈 대화를 깨끗이 비우고 새 대화 시작 가계부 만들다가 폴더 정리 등 다른 주제로 넘어갈 때 필수! (사용량 절약 1등 비결)
/compact 길어진 대화의 핵심만 요약해서 기억 공간 확보 한 가지 작업을 오래 이어가다 대화가 너무 길어졌을 때
/init 현재 폴더를 분석해 AI용 인수인계 노트 자동 생성 자주 작업하는 폴더에서 AI가 매번 내 규칙(한국어 답변 등)을 기억하게 할 때
/help 사용 가능한 전체 명령어와 단축키 안내 보기 명령어가 갑자기 기억나지 않을 때 언제든 입력
Ctrl + C (또는 Esc) AI가 작업 중일 때 즉시 일시정지(멈춤) AI가 내가 원치 않는 방향으로 만들고 있을 때 바로 멈추고 다시 지시!
/exit AI 에이전트 대화를 완전히 마치고 빠져나오기 작업을 다 끝내고 일반 터미널로 돌아가거나 창을 닫기 전

🤝 세 가지 도구를 다 깔았다면, 언제 뭘 켜면 좋을까요?

같은 폴더(ai-workspace) 안에서 기분에 따라 번갈아 켜도 같은 파일을 이어받아 작업할 수 있습니다.

🟠 Claude Code (claude)

글쓰기·디자인 감각·전체 기획의 올라운더. 웹페이지 디자인을 예쁘게 뽑거나, 문서를 매끄럽게 요약·정리하고, 막연한 아이디어를 알아서 척척 구조화할 때 가장 먼저 켜기 좋습니다.

🔵 Antigravity (agy / 앱)

마우스 화면(앱) 지원 & 넉넉한 무료 시작. 검은 터미널 창이 어색할 때 데스크톱 앱으로 파일 목록과 결과 화면을 눈으로 보며 작업하기 좋고, 다른 도구 한도가 찼을 때 든든한 파트너가 됩니다.

🟢 OpenAI Codex (codex)

논리적인 계산·꼼꼼한 오류 해결사. 복잡한 엑셀 수식·데이터 통계 검증을 시키거나, 잘 안 풀리는 까다로운 버그를 끝까지 파고들어 정확하게 고쳐낼 때 진가를 발휘합니다.

PART 5 · SAFETY RULES

내 소중한 파일 지키는 초보자 안전 수칙 3계명

실제 파일을 다루는 강력한 비서인 만큼, 아래 3가지만 지키면 100% 안전하게 쓸 수 있습니다.

1️⃣ 항상 '전용 작업 폴더' 안에서 켜기

C:\ 드라이브 전체나 내 문서 최상위에서 바로 실행하지 마세요. 작업할 것만 모아둔 전용 폴더(예: ai-workspace)에 들어가서 켜면 그 폴더 바깥은 건드리지 않아 완벽히 안전합니다.

2️⃣ 원본 사진·중요 장부는 '복사본'으로!

가족사진 이름 바꾸기나 회사 원본 엑셀 정리를 처음 시킬 때는 원본 폴더를 그대로 복사(Ctrl+C → Ctrl+V)해 테스트 폴더에서 먼저 시켜보는 습관을 들이세요.

3️⃣ '파일 삭제(rm / del)' 질문만 한 번 더 보기

새 파일을 만들거나 읽는 건 언제든 Yes를 눌러도 괜찮지만, AI가 기존 파일을 삭제(Delete / rm)하겠다고 물어볼 때만 꼭 파일 이름을 눈으로 한 번 확인하고 승인하세요.
